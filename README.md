# 8-Bit ALU Design Using Verilog HDL

## Project Overview
Designed an 8-bit Arithmetic Logic Unit (ALU) using Verilog HDL and worked with Synopsys Fusion Compiler as part of the digital implementation flow.

## Design Features
- 8-bit input operands (A and B)
- 3-bit opcode for operation selection
- Combinational RTL design
- Arithmetic and logical operations
- Zero flag output
